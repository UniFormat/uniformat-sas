# Contributing to uniformat-sas

The organisation-wide rules (`UniFormat/.github`) apply. Format-specific rules:

## Reading rules for sources (clean room)

- **Free to read:** ReadStat (except `src/sas/ieee.c`), `pyreadstat`, Parso >= 2.0.8 (never <= 2.0.7, GPL v3), pandas,
  the Python `sas7bdat` package, `FredHutch/sas7bdat`, the Rust `sas7bdat` crate, `polars-readstat-rs`, `readstat-rs`,
  `statfmt`, `datareader`, `richokelly/sas7bdat`, `cpp-sas7bdat`, `SASLib.jl`.
- **Documentation only (not the code):** the R `sas7bdat` package, `sasquatch` (Rust and Java, EUPL), `sas7bdat-js`,
  `goreadstat`, `FredHutch/sas7bdat-specification`.
- **Do not read:** sources without a license (`SAS-reader`, `quick-sas7bdat`, `rust-sas-reader`, `readstat-go`, DuckDB
  extensions, npm packages).
- The Shotwell PDF (CC BY-SA 3.0) may be read for facts, never copied.
- The code follows `docs/spec` (`10`, `15`, `20`, `30`, `60`). A mismatch between code and specification means the
  **specification is corrected first**, not only the code.
- A SAS installation and decompiler output are not code sources.

## Rules for the codec crate `uniformat-sas` (ADR 0001, ADR 0007)

- Production dependencies: `thiserror`, `encoding_rs`, `memchr` only (`ci/check_core_deps.sh`).
- No I/O (`std::fs`, `std::net`, `std::thread`), no `unsafe`.
- No public function panics on invalid input: `unwrap`, `expect`, `panic!`, direct indexing and unchecked arithmetic are
  denied by clippy. Use `get`, `checked_*`, `from_le_bytes` on checked slices.
- Every allocation derived from a file field is bounded by `Limits`.

## Tests

```bash
cargo test --workspace --exclude uniformat-sas-py
UNIFORMAT_CORPUS=<corpus> cargo test --workspace --exclude uniformat-sas-py
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all -- --check
ci/check_core_deps.sh
python3 -I ci/gen_tables.py --check
```

Files produced by a licensed SAS installation must not be committed. Only files with a redistributable license (see
`uniformat-conformance/data`) or files generated by this driver may be added.

## MSRV

`rust-version` in `Cargo.toml` (ADR 0007 §3); the CI `msrv` job must use the same version. It never goes below the one of
`arrow` and `datafusion`.
